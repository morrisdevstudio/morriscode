# Local voice narration

MorrisCode can read completed assistant explanations aloud with a local Kokoro
text-to-speech model. The engine runs in a separate Python process and uses the
CPU build of ONNX Runtime. It does not request a GPU, send response text to a
third party, or persist generated audio.

## User flow

A speaker button appears below completed responses that contain readable text.
The adjacent language selector defaults to French and also offers English.
Playback supports pause, resume, and stop. Starting another response or changing
sessions stops the current playback.

The browser reads only the returned audio. This means a phone connected to a
LAN-hosted MorrisCode instance can listen to the same local engine; the audio
travels through the existing authenticated HTTPS connection.

## Data and resources

The guided installation runs from the speaker button and stores its isolated
runtime under the application data directory:

- Windows: `%LOCALAPPDATA%\morriscode\speech` or `%LOCALAPPDATA%\morriscode-dev\speech`
- macOS: `~/Library/Application Support/morriscode/speech`
- Linux: `${XDG_DATA_HOME:-~/.local/share}/morriscode/speech`

The download is about 142 MB:

- `kokoro-v1.0.int8.onnx`
- `voices-v1.0.bin`

Downloads are checked against pinned SHA-256 digests. The Python environment
uses Python 3.12 and pinned `kokoro-onnx` dependencies installed through `uv`.
The installer requires `uv` on `PATH`.

The engine loads on the first synthesis and shuts down after two minutes without
an active or queued synthesis. Only one synthesis request is accepted at a time.
The browser keeps at most one chunk ready for playback and drops prepared audio
when playback stops or changes.

## Speech content

Speech preparation happens in the server. It keeps headings, list text, table
cells, and link labels. It removes fenced code blocks, URLs, HTML markup, and
tool or reasoning output. Text is split into chunks of at most 180 characters,
and synthesis rejects chunks over 600 characters.

## Verification

Unit and integration coverage:

```bash
npx vitest run src/shared/speech.test.ts src/server/routes/speech.test.ts
npx vitest run web/src/stores/speechPlayback.test.ts web/src/components/plan/SpeechButton.test.tsx
```

Manual check:

1. Open a completed conversation and press the speaker under a response.
2. Follow the guided installation and confirm progress reaches 100%.
3. Verify playback starts, pause/resume works, and stop cancels both audio and generation.
4. Read a long response containing code; code blocks should stay silent.
5. Switch English/French in the selector and verify both voices.
6. Open the same conversation from a phone using the configured HTTPS address.
7. After two minutes idle, confirm the Python worker no longer appears in Task Manager or `ps`.
